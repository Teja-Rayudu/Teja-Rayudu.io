## 🔧 Customization

### Update Personal Information
1. Open `index.html`
2. Replace "Teja Rayudu" with your name
3. Update email in contact forms
4. Modify social links (GitHub, LinkedIn, LeetCode)

### Change Colors
1. Open `styles.css`
2. Modify CSS variables in `:root` section
3. Update color values as needed

### Update Content
- **Projects**: Edit `.project-card` sections
- **Skills**: Modify `.skill-tags` content
- **Achievements**: Update `.achievement-card` sections
- **About**: Edit `.about-paragraph` and `.facts-list`
